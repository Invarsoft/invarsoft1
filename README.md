## 🚀 Quick Start & Windows Batch Scripts

### Windows One-Click Batch Scripts:

| Batch Script | Function |
| :--- | :--- |
| `start_server.bat` | Installs dependencies, builds project, and starts production server on `http://localhost:3000` |
| `github_push.bat` | Automates Git init, commit, and push directly to your GitHub repository |
| `build_project.bat` | Runs production build verification (`npm run build`) |
| `install_dependencies.bat` | Cleanly installs all `node_modules` (`npm install`) |

---

## 💻 Manual Terminal Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build & Run Production Server
```bash
npm run build
npm start
```

## ☁️ Deployment Instructions

### Deploy to Vercel (Recommended)
1. Push your code to GitHub using `github_push.bat` or Git.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository.
4. Vercel will automatically detect **Next.js** and deploy in < 60 seconds!
